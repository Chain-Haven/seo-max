Connect your WordPress/WooCommerce site to SEO Max for centralized SEO management and AI-powered content optimization.

== Description ==

SEO Max Connector is a WordPress plugin that connects your site to the SEO Max platform, enabling:

* **Centralized SEO Management** - Manage meta titles, descriptions, and schema markup for all your products, pages, and posts from one dashboard.
* **AI-Powered Optimization** - Generate optimized meta tags, alt texts, and content using advanced AI.
* **Automated Blog Content** - Let AI create and publish SEO-optimized blog posts automatically.
* **Real-time Sync** - Keep your site's SEO data synchronized with the platform.
* **WooCommerce Integration** - Full support for WooCommerce products and categories.

= Features =

* Easy one-click connection with API key
* Automatic synchronization of products, pages, and posts
* Support for major SEO plugins (Yoast, Rank Math, All in One SEO, SEOPress)
* Webhook support for receiving updates from the platform
* Schema markup injection
* Bulk alt text management
* Sync logging and status tracking

= Requirements =

* WordPress 5.8 or higher
* PHP 7.4 or higher
* An active SEO Max account

== Installation ==

1. Download the plugin from your SEO Max dashboard
2. Upload to your WordPress site via Plugins > Add New > Upload Plugin
3. Activate the plugin
4. Go to SEO Max in your admin menu
5. Enter your API key from the SEO Max dashboard
6. Click "Test Connection" to verify
7. Click "Sync All Data Now" to send your site data to SEO Max

== Frequently Asked Questions ==

= Where do I get my API key? =

Log in to your SEO Max dashboard at https://seo-max-pink.vercel.app, go to your store settings, and copy the API key.

= Does this work with WooCommerce? =

Yes! The plugin fully supports WooCommerce products, categories, and variations.

= What SEO plugins are supported? =

The plugin works with Yoast SEO, Rank Math, All in One SEO, and SEOPress. It reads and writes to their meta fields.

= Is my data secure? =

Yes. All data is transmitted over HTTPS, and each connection is authenticated with a unique API key.
