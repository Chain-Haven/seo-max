Advanced SEO optimization for WordPress & WooCommerce with AI-powered improvements, rank tracking, and comprehensive SEO management.

== Description ==

SEO Max is a comprehensive SEO plugin designed specifically for WordPress and WooCommerce sites. It provides:

**Key Features:**

* **AI-Powered Content Optimization** - Real-time SEO scoring and suggestions as you write
* **Rank Tracking** - Monitor your keyword rankings with historical charts
* **Keyword Research** - Find high-value keywords with search volume and difficulty data
* **Schema Markup** - Automatic generation and validation of structured data
* **Site Audits** - Comprehensive technical SEO audits with actionable recommendations
* **Competitor Analysis** - Discover keyword gaps and opportunities
* **WooCommerce Integration** - Product feed generation, schema for products, out-of-stock handling
* **Bulk Operations** - Generate meta data, alt text, and schema for multiple items at once
* **Conflict Detection** - Works alongside Yoast, Rank Math, and other SEO plugins without conflicts

**WooCommerce Specific:**

* Product schema with reviews, pricing, and availability
* Shopping feed generation (Google Shopping, Facebook)
* Product variation handling
* Out-of-stock SEO strategy
* Category page optimization
* Performance optimization for large catalogs

**Non-Conflicting Design:**

SEO Max detects other SEO plugins (Yoast, Rank Math, etc.) and automatically adjusts to avoid conflicts. It can:
* Work alongside existing plugins for analytics, rank tracking, and audits
* Optionally take over meta management if you choose
* Add complementary features without overwriting existing setups

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/seo-max/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to SEO Max > Settings to enter your API key from the SEO Max platform
4. Configure sync preferences and conflict resolution
5. Start optimizing!

== Frequently Asked Questions ==

= Does this conflict with Yoast SEO or Rank Math? =

No! SEO Max automatically detects other SEO plugins and works alongside them. It adds complementary features like rank tracking, competitor analysis, and advanced reporting that other plugins don't have. For meta management, you can choose which plugin takes priority.

= Do I need a SEO Max platform account? =

Yes, SEO Max connects to the SEO Max platform (https://seo-max-pink.vercel.app) for AI-powered features, rank tracking, and analytics. Sign up for a free account to get started.

= Does this work with WooCommerce? =

Yes! SEO Max has extensive WooCommerce integration including product schema, shopping feed generation, and bulk product optimization.

= Can I use this for local SEO? =

Yes! SEO Max includes local rank tracking, NAP consistency checking, and Google Business Profile integration.
