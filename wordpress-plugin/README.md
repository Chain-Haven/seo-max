# SEO Max WordPress Plugins

## Official plugin: SEO Max Connector

**Download:** Use the **SEO Max Connector** plugin. In the dashboard go to **Settings → Download Plugin** to get `seo-max-connector.zip`.

- **One plugin** – Connect with API key only (no manual store ID). Syncs pages, posts, and products. Compatible with our API.
- **Location:** `seo-max-connector/` (distributed as `seo-max-connector.zip`)

## Flow after signup

1. User creates a store in SEO Max and gets an API key.
2. User installs **SEO Max Connector** on their WordPress/WooCommerce site and enters the API key.
3. User clicks **Connect** in the plugin. The platform marks the store as connected and **automatically starts a site scan** (crawl + AI improvements).
4. When the scan finishes, the store has:
   - Crawl data in **Site Audit**
   - SEO improvements in **AI Improvements** (Audit findings tab and plugin `/improvements` API).

No duplicate plugins are needed; use **SEO Max Connector** only.
